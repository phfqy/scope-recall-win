# 远端接入配置说明（应用 / MCP / SKILL）

本文说明三种接法。**它们读写的是同一份云端账本**（`state.json` + `records/<sha1(ref)>.json`），
任选其一即可，不必同时开两个写通道做同一件事。

| 接法 | 适合 | 需要什么 |
|---|---|---|
| ① 桌面应用 | 想在本机看状态、管记忆、触发同步 | Windows 10 19041+ |
| ② MCP Server | 客户端原生支持 MCP（Codex / Claude / Hermes） | `mcp>=2.0` |
| ③ SKILL + CLI | 任何环境；脚本 / cron / 无 MCP 客户端 | 零第三方依赖（local 后端） |

---

## 0. 先理解数据流

```
远端 agent ──(① 应用 / ② MCP / ③ CLI)──► 云端账本
                                          │
                       本机云桥 bridge/cloudsync_run.py
                                          │ 官方 propose_memory（含去重、证据累积）
                                          ▼
                                 scope-recall 共享记忆库
```

两个必须接受的语义：

1. **写入是「提议」**：远端写上去的是 `proposed` 记录，由本机云桥转正，**不会即时可见**。
2. **远端从不直接写共享库**：远端只能写云端账本；落库一律由本机云桥转写。

## 1. 桌面应用（控制台）

### 安装

下载 [Release](https://github.com/phfqy/scope-recall-win/releases/latest) 的
`ScopeRecallWin-Setup-<版本>.exe`，双击即可（per-user，免管理员）：

```powershell
ScopeRecallWin-Setup-<版本>.exe            # 图形安装，如 1.3.7
ScopeRecallWin-Setup-<版本>.exe /VERYSILENT   # 静默安装
```

安装位置 `%LOCALAPPDATA%\Programs\ScopeRecallWin`，卸载走「设置 → 应用」。

### 配置云同步

1. 打开 **云同步** 页 → **开始自检**
   需要一个带 `mcp` / `webdav4` / `boto3` 的 Python 环境，
   建议点「选择 Python…」指向一个**专用 venv**（放在安装目录之外，以后升级不丢）。
2. 填云端配置：

   | 字段 | 坚果云填法 |
   |---|---|
   | 后端 | `webdav` |
   | 地址 | `https://dav.jianguoyun.com/dav/` |
   | 账号 | 你的坚果云**邮箱** |
   | 密码 | **应用密码**（网页版「安全选项 → 添加应用密码」生成）——登录密码会 401 |
   | 根路径 | `scope-recall`（云端目录名） |

   S3 兼容存储选后端 `s3`，另填 bucket / endpoint / access key / secret key。
3. 填**授权说明**（必填，不代笔、不预填）→ 保存配置。
4. 点 **「备份并同步一轮」**：先调官方 backup 做一致性快照，备份失败即中止。

> 密码只进 Windows 凭据管理器，经**环境变量**注入子进程，
> 不进命令行参数、不进 `settings.json`、不进日志。

### 远端链接状态

云同步页底部「**远端 agent 链接状态**」→ 点「检查远端」：

- 只读探针 `bridge/remote_status.py` 扫云端账本，按 `origin_agent` 聚合；
- 本机主桥推的记录没有该字段，归为 `home（本机主桥）`；
- 发现远端写入者时，卡片会提示「点『备份并同步一轮』拉取」——**远端写入必须跑一轮才进共享库**。

## 2. MCP Server 接入

### 前置

```bash
python -m pip install "mcp>=2.0"
```

`remote/memory_mcp.py` 与 `remote/sr_cloud_remote.py` 必须**同目录**（前者 import 后者）。

### 启动方式（stdio）

```bash
python remote/memory_mcp.py \
  --db  <本地镜像库路径，如 D:\sr\sr-cloud-mirror.sqlite3> \
  --backend webdav \
  --url  https://dav.jianguoyun.com/dav/ \
  --user <坚果云邮箱> \
  --pwd  <应用密码> \
  --root scope-recall
```

也可用环境变量替代参数：`SR_CLOUD_BACKEND / SR_CLOUD_ROOT / SR_CLOUD_URL / SR_CLOUD_USER /
SR_CLOUD_PWD / SR_CLOUD_BUCKET / SR_CLOUD_ENDPOINT / SR_CLOUD_ACCESS_KEY / SR_CLOUD_SECRET_KEY /
SR_CLOUD_DB`。

### 客户端注册示例

**Claude 桌面版 / Claude Code**（`claude_desktop_config.json`）：

```json
{
  "mcpServers": {
    "scope-recall-cloud-memory": {
      "command": "python",
      "args": [
        "E:\\path\\to\\remote\\memory_mcp.py",
        "--db", "E:\\sr\\sr-cloud-mirror.sqlite3",
        "--backend", "webdav",
        "--url", "https://dav.jianguoyun.com/dav/",
        "--user", "you@example.com",
        "--root", "scope-recall"
      ],
      "env": {
        "SR_CLOUD_PWD": "<应用密码>"
      }
    }
  }
}
```

> 把密码放 `env` 而不是 `args`，理由同应用侧：命令行参数对同机其他用户可见。

**OpenAI Codex**（`mcp.json` / 等价配置）：

```json
{
  "mcpServers": {
    "scope-recall-cloud-memory": {
      "command": "python",
      "args": ["E:\\path\\to\\remote\\memory_mcp.py",
               "--db", "E:\\sr\\sr-cloud-mirror.sqlite3",
               "--backend", "webdav", "--url", "https://dav.jianguoyun.com/dav/",
               "--user", "you@example.com", "--root", "scope-recall"],
      "env": { "SR_CLOUD_PWD": "<应用密码>" }
    }
  }
}
```

**Hermes**：同样是 stdio server，注册命令与参数照抄上面即可。

### 七个工具

| 工具 | 参数 | 说明 |
|---|---|---|
| `status` | — | 镜像条数 + 云端账本概览（记录 / claims / events） |
| `recall` | `query`, `limit=20`, `kind=""` | 镜像内 LIKE 检索（subject / predicate / value_text / 事件正文） |
| `inspect` | `subject`, `limit=50` | 按实体列出全部记忆 |
| `remember` | `subject`, `value`, `predicate=""`, `kind="fact"`, `note=""`, `force=false` | 写入一条记忆（等价 CLI 的 `propose`） |
| `revise` | `ref`, `value=""`, `predicate=""`, `kind=""`, `subject=""`, `force=false` | 修订一条已上云的记忆 |
| `forget` | `ref`, `note=""`, `force=false` | 软删除（`state=superseded`，云桥不再转写） |
| `sync` | — | 手动拉云端 → 本地镜像（增量 + SHA256 校验） |

**没有 `mcp` 包时**可以直接验证全部逻辑（不起服务）：

```bash
python remote/memory_mcp.py --backend local --root ./cloud --selftest
```

## 3. SKILL + CLI 接入

### 安装 skill

把 `remote/` 下的 `SKILL.md`、`sr_cloud_remote.py`、`memory_mcp.py` 一起放到 agent 的 skills 目录，例如：

```
<skills 目录>/sr-cloud-memory/
├── SKILL.md
├── sr_cloud_remote.py
└── memory_mcp.py
```

agent 会按 `SKILL.md` 里的描述（关键词：远端记忆、云端记忆、跨端记忆）
在需要时自动加载并调用 CLI。

### 环境变量

```bash
export SR_CLOUD_BACKEND=webdav            # local | webdav | s3
export SR_CLOUD_URL=https://dav.jianguoyun.com/dav/
export SR_CLOUD_USER=<坚果云邮箱>
export SR_CLOUD_PWD=<应用密码>
export SR_CLOUD_ROOT=scope-recall
export SR_CLOUD_DB=./sr-cloud-mirror.sqlite3   # 本地镜像，可省（默认当前目录）
```

### 七个命令

```bash
# 拉取云端 → 本地镜像（增量；校验不过的记录跳过）
python sr_cloud_remote.py sync

# 检索（先 sync 再 recall）
python sr_cloud_remote.py recall "关键词" [--limit 20] [--kind fact] [--json]
python sr_cloud_remote.py show <ref>

# 状态：镜像统计；加 --cloud 附云端概览
python sr_cloud_remote.py status --cloud

# 写回：提议一条记忆（拿到 ref 供后续 revise/forget 用）
python sr_cloud_remote.py propose --subject "DSH" --predicate "uses" --value "Zen browser" --kind fact

# 修订 / 废弃（默认只作用于本 agent 自己提议的记录）
python sr_cloud_remote.py revise <ref> --value "新内容"
python sr_cloud_remote.py forget <ref>
```

- `--kind` 取值：`fact` / `preference` / `constraint` / `decision` / `procedure` / `intention` / `alias`。
- `revise` / `forget` 动他人记录需 `--force`（或 MCP 的 `force=true`）——**先问过主人**。
- 也可以直接用 skill 目录里的副本：
  `python <skills>/sr-cloud-memory/sr_cloud_remote.py …`

### local 后端（不联网跑通）

```bash
python sr_cloud_remote.py propose --subject test --value hello --backend local --root ./cloud
python sr_cloud_remote.py sync   --backend local --root ./cloud
python sr_cloud_remote.py recall hello --backend local --root ./cloud --json
```

`--root` 指向的目录即「云端」，内容结构就是 `state.json` + `records/`。

## 4. 排错

| 现象 | 原因 / 处理 |
|---|---|
| `401 Unauthorized`（坚果云） | 用了登录密码。**必须用应用密码**（网页版「安全选项 → 添加应用密码」） |
| `503` / 请求被挡 | 坚果云免费版限流（全局限流，窗口数分钟~数小时）。降低频率、分批操作；桥会跳过本轮继续 |
| `integrity_skipped > 0` | 记录内容与账本 hash 不符（被截断/篡改）→ 宁缺毋滥直接跳过，重跑一次 sync |
| `（镜像中无匹配记忆；先跑一次 sync）` | 本地镜像还是空的，先 `sync` |
| `denied / 这条不是本 agent 写的` | `revise` / `forget` 默认只改自己提议的记录；确需修改加 `--force` |
| `already_forgotten` | 该记录已 `superseded`；要恢复内容需重新 `propose` |
| 云同步页「写入了但控制台看不到」 | 远端写入是 `proposed`，需本机跑一轮同步（云桥转写）后才进共享库 |
| MCP 启动报缺少 `mcp` 包 | `python -m pip install "mcp>=2.0"`，或改用零依赖的 CLI |
| 云同步页提示找不到专用 venv | 点「选择 Python…」选一个装了 `mcp`/`webdav4`/`boto3` 的解释器 |
| 界面文案是旧的（改过 XAML 后） | XAML 改动必须同步 `.pri` 与 `*.xbf`，否则加载的是旧资源 |

## 5. 不要做的事

- **不要手工编辑**云端 `state.json`（它是多写入者共用的协调账本，读改写会保留他人条目）。
- **不要让远端直连共享记忆库**（`memory.sqlite3`）——落库必须经官方 `propose_memory`。
- **不要同时用两套云端协议**：整文件形态（`memory.sqlite3` + `memory.jsonl`）与本增量账本
  互不可见。`bridge/memory_mcp.py`（交付包旧版）已弃用，改用 `remote/memory_mcp.py`。
